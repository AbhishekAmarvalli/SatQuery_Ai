SLIDE 2: SATQUERY AI

Proposed Solution

Slide text:
- Multimodal Input: Supports Optical, SAR, and Thermal remote-sensing imagery.
- Natural-Language Queries: Users can ask questions about satellite imagery using
- simple text.
- AI-Powered Analysis: A Vision-Language Model (LLaVA) interprets both the user’s
- query and satellite image content.
- Geospatial Grounding: SAM / CLIP-BLIP components connect the AI's response to
- specific regions in the image.
- Interactive Map Output: Results are displayed on a React + Leaflet/OpenLayers
- interface with relevant areas highlighted.
- Geospatial Backend: FastAPI + PostgreSQL/PostGIS manages queries, imagery and
- spatial results.
- Key Innovation: Combines Vision-Language AI + multimodal remote sensing
- + geospatial grounding in one query-driven workflow
